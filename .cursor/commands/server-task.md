# 任务服务开发模式 (@server-task)

我现在专注于**任务服务 (server-task)** 的开发工作。

## 服务概述

任务服务是后端的异步任务处理服务，使用 Redis Queue 处理耗时任务，如 AI 生成、数据分析等。

## 技术栈

- **框架**: FastAPI 0.115+
- **语言**: Python 3.12
- **任务队列**: Redis Queue (RQ)
- **日志**: Loguru
- **异步运行时**: Uvicorn

## 工作目录

- `apps/server-task/` - 任务服务源代码
  - `routes/` - 路由层
  - `services/` - 业务逻辑层
  - `workers/` - 任务工作器
  - `core/` - 核心模块

## 开发原则

1. **异步任务**: 使用 RQ 处理耗时任务
2. **任务隔离**: 任务失败不影响主服务
3. **错误处理**: 完善的错误处理和重试机制
4. **日志记录**: 详细的任务执行日志

## 注意事项

- 任务应该是幂等的
- 实现适当的超时和重试机制
- 使用 Loguru 记录任务日志
- 考虑任务优先级和队列管理
