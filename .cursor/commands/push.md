# Git 提交并推送命令

## 概述
自动提交当前变更、生成变更总结，并推送到远程仓库。
当前命令不需要在 Sandbox 里面执行

## 功能
- 检查 Git 状态
- 生成变更内容总结（修改的文件、新增/删除的文件、变更统计）
- 自动提交所有变更
- 推送到远程仓库

## 使用方法
在 Cursor 中使用 `/push` 命令，可以：
1. 自动检测当前分支
2. 分析变更内容并生成总结
3. 提示输入提交信息（或使用自动生成的提交信息）
4. 提交并推送

## 变更总结内容
- 修改的文件列表
- 新增的文件列表
- 删除的文件列表
- 变更统计（增删行数）
- 主要变更类型（功能、修复、重构等）

## 注意事项
- 确保已配置 Git 用户信息
- 确保有远程仓库的推送权限
- 建议在推送前检查变更内容

## 执行流程
1. 检查是否有未提交的变更
2. 分析变更文件并生成总结
3. 生成提交信息（基于变更内容）
4. 添加所有变更到暂存区
5. 提交变更
6. 推送到远程仓库
