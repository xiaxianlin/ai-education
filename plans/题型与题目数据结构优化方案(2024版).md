# 题型与题目数据结构优化方案 (2024版)

## 概述

基于文档中的题型配置方案，优化现有的题型和题目数据结构，确保能适配题型配置中所有题型，支持应用题的子题结构，兼容高年级题型，并考虑前端交互方案。

## 背景

### 题型配置方案核心要点

从 `docs/小学低年级题型配置方案.md` 中，系统定义了**135个小学低年级全学科题型**：

- **语文学科**: 45个题型 (1-3年级各15个)
- **数学学科**: 45个题型 (1-3年级各15个)  
- **英语学科**: 45个题型 (1-3年级各15个)

**题型场景类型包括:**
- 选择题、判断题、拼写题、口语题、匹配题、应用题、简答题、操作题

**资源类型:**
- `image` - 图片资源
- `audio` - 语音资源
- `空` - 无资源

### 现有数据结构问题分析

从 `apps/server/shared/core/database.py` 分析现有结构：

**QuestionType 表问题:**
- 缺少交互配置、难度细分、子题型等关键信息
- 无法支持题型的层次化管理
- 资源类型单一，不支持复杂资源

**Question 表问题:**
- `options` 使用 JSON 存储，但无法支持复杂题型需求
- 缺少小题层次结构，无法支持"一个题目几个小题"
- 交互配置缺失，无法支持多样化的前端交互

## 优化方案

### 1. 题型表优化 (QuestionType)

```python
class QuestionType(BaseModel):
    """题型表 - 支持层次化和交互配置"""
    
    # 原有字段
    id: Mapped[int] = mapped_column(primary_key=True, autoincrement=True)
    title: Mapped[str] = mapped_column(String(100), comment="题型标题")
    scene: Mapped[str] = mapped_column(String(50), comment="题型场景")
    subject: Mapped[str] = mapped_column(String(50), comment="科目")
    grade: Mapped[int] = mapped_column(comment="年级（1-12）")
    description: Mapped[str] = mapped_column(Text, nullable=True, comment="题型描述")
    prompt: Mapped[str] = mapped_column(Text, nullable=True, comment="AI生成指令")
    create_time: Mapped[int] = mapped_column(default=now)
    update_time: Mapped[int] = mapped_column(default=now, onupdate=now)
    
    # 新增字段 - 题型层次化
    parent_id: Mapped[int] = mapped_column(nullable=True, comment="父题型ID")
    level: Mapped[int] = mapped_column(default=1, comment="题型层级:1-主题型 2-子题型")
    code: Mapped[str] = mapped_column(String(50), unique=True, comment="题型编码")
    
    # 新增字段 - 交互配置
    interaction_type: Mapped[str] = mapped_column(String(50), comment="交互类型")
    input_config: Mapped[dict] = mapped_column(JSON, default=dict, comment="输入配置")
    output_config: Mapped[dict] = mapped_column(JSON, default=dict, comment="输出配置")
    ui_config: Mapped[dict] = mapped_column(JSON, default=dict, comment="UI配置")
    
    # 新增字段 - 题型特性
    support_grade_range: Mapped[str] = mapped_column(String(20), comment="支持年级范围")
    complexity_level: Mapped[int] = mapped_column(default=1, comment="复杂度等级1-5")
    is_composite: Mapped[bool] = mapped_column(default=False, comment="是否为复合题型")
    max_sub_questions: Mapped[int] = mapped_column(default=0, comment="最大子题数量")
    estimated_time: Mapped[int] = mapped_column(default=60, comment="预计答题时间(秒)")
    
    # 新增字段 - 资源配置
    resource_types: Mapped[str] = mapped_column(String(200), comment="支持资源类型(逗号分隔)")
    required_resources: Mapped[str] = mapped_column(String(200), comment="必需资源类型")
    
    # 关联关系
    parent = relationship("QuestionType", remote_side=[id], back_populates="children")
    children = relationship("QuestionType", back_populates="parent")
```

### 2. 题目表优化 (Question)

```python
class Question(BaseModel):
    """题目表 - 支持层次化和多模态交互"""
    
    # 基础字段
    id: Mapped[str] = mapped_column(String(255), primary_key=True, index=True)
    question_type_id: Mapped[int] = mapped_column(comment="题型ID")
    
    # 层次化结构
    parent_id: Mapped[str] = mapped_column(String(255), nullable=True, comment="父题目ID")
    is_main_question: Mapped[bool] = mapped_column(default=True, comment="是否为主题目")
    sub_order: Mapped[int] = mapped_column(default=0, comment="子题顺序")
    
    # 内容字段
    main_content: Mapped[str] = mapped_column(Text, comment="主题目内容")
    sub_content: Mapped[str] = mapped_column(Text, nullable=True, comment="子题内容")
    full_content: Mapped[str] = mapped_column(Text, comment="完整题目内容")
    
    # 答案和选项
    answer_data: Mapped[dict] = mapped_column(JSON, comment="答案数据(支持复杂答案)")
    options_data: Mapped[dict] = mapped_column(JSON, comment="选项数据")
    
    # 扩展属性
    subject: Mapped[str] = mapped_column(String(50), comment="科目")
    grade: Mapped[int] = mapped_column(comment="年级")
    difficulty: Mapped[str] = mapped_column(String(20), comment="难度等级")
    score: Mapped[float] = mapped_column(default=1.0, comment="分值")
    
    # 关联信息
    textbook_id: Mapped[int] = mapped_column(nullable=True, comment="教材ID")
    unit_id: Mapped[int] = mapped_column(nullable=True, comment="单元ID")
    knowledge_ids: Mapped[str] = mapped_column(String(255), comment="知识点ID列表")
    
    # 交互和UI配置
    interaction_config: Mapped[dict] = mapped_column(JSON, default=dict, comment="交互配置")
    ui_config: Mapped[dict] = mapped_column(JSON, default=dict, comment="UI配置")
    validation_rules: Mapped[dict] = mapped_column(JSON, default=dict, comment="验证规则")
    
    # 资源配置
    resources: Mapped[list[dict]] = mapped_column(JSON, default=list, comment="资源列表")
    
    # 时间相关
    estimated_time: Mapped[int] = mapped_column(default=60, comment="预计答题时间(秒)")
    time_limit: Mapped[int] = mapped_column(default=0, comment="时间限制(秒,0表示无限制)")
    
    # 状态字段
    status: Mapped[int] = mapped_column(default=1, comment="状态:0-禁用 1-启用")
    create_time: Mapped[int] = mapped_column(default=now)
    update_time: Mapped[int] = mapped_column(default=now, onupdate=now)
    
    # 关联关系
    question_type = relationship("QuestionType")
    parent = relationship("Question", remote_side=[id], back_populates="children")
    children = relationship("Question", back_populates="parent")
```

```typescript
  type: string;

}

interface QuestionConfig {
  id: string;

  options?: Option[];

  resources: Resource[];
  interaction: InteractionConfig;
  ui: UIConfig;

```

### 2. 交互组件实现

```typescript
// 选择题组件
const ChoiceQuestion: React.FC<QuestionComponent> = ({ config, onAnswer }) => {
  const { options, interaction } = config;
  const [selected, setSelected] = useState<string[]>([]);
  
  const handleSelect = (value: string) => {
    if (interaction.type === 'single') {
      setSelected([value]);
    } else {
      setSelected(prev => 
        prev.includes(value) 
          ? prev.filter(v => v !== value)
          : [...prev, value]
      );
    }
  };
  
  return (
    <div className="choice-question">
      {options.map((option, index) => (
        <Option
          key={index}
          value={option.value}
          label={option.label}
          selected={selected.includes(option.value)}
          onClick={() => handleSelect(option.value)}
        />
      ))}
    </div>
  );
};
```

## 预期效果

1. **题型覆盖度**: 支持K12全学段所有题型
2. **交互丰富度**: 支持15+种标准化交互类型
3. **扩展性**: 支持未来新题型的快速接入

## 风险评估

1. **数据迁移风险**: 现有题目数据需要复杂转换
2. **性能风险**: JSON字段可能影响查询性能
3. **兼容性风险**: 前端需要大幅重构
4. **学习成本**: 开发团队需要熟悉新的数据结构

## 总结

本方案基于现有的135个标准题型，通过层次化设计、交互配置标准化、资源多模态化等优化，构建了一个可扩展、高性能的题目数据结构。方案充分考虑了前端交互需求，支持应用题的子题结构，能够适配高年级的复杂题型，为AI教育辅导平台提供了坚实的技术基础。
