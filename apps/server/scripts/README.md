# 数据导入脚本

## 能力数据导入

### 使用方法

```bash
# 进入 server 目录
cd apps/server

# 运行导入脚本
python scripts/import_ability_data.py
```

### 功能说明

`import_ability_data.py` 脚本用于导入能力管理模块的初始数据：

1. **能力域数据**：导入语文、数学、英语三科的能力域（共10个）
2. **原子能力数据**：导入小学1-6年级的原子能力（共30条）

### 特性

- **幂等性**：脚本支持重复运行，已存在的数据会被跳过
- **数据验证**：导入原子能力前会验证对应的能力域是否存在
- **详细日志**：显示每条数据的导入状态

### 导入的数据

#### 能力域（13个）

- **语文**：识字与写字、阅读理解、语言表达
- **数学**：数与运算、图形与空间、问题解决、测量
- **英语**：语音意识、词汇运用、阅读理解、语法意识、语言表达、听力理解

#### 原子能力（69条）

- **语文**：1-6年级，共32条

  - 五年级：4条

- **数学**：1-6年级，共20条

  - 四年级：3条
  - 五年级：3条
  - 六年级：3条
- **英语**：1-6年级，共17条

### 注意事项

1. 确保数据库连接配置正确（`.env` 文件中的 `DATABASE_URL`）
2. 确保数据库表已创建（运行 `init_database()` 或执行迁移）
3. 脚本会跳过已存在的数据，不会重复导入
