## 二、题目类型说明
输入题要求学生通过文本输入或语音输入的方式回答问题。题目可以包含文字、图片、音频等资源类型。**注意：仅支持图片和音频两种资源类型，不支持视频、动画或复合资源。**

## 三、资源类型与生成规范

### 3.1 纯文字资源（text/none）
**适用场景**：文字描述题、计算题、简答题等

**生成要求**：
- 题干使用 `stem.text` 字段，清晰描述题目要求
- 不需要额外的资源字段
- 语言简洁明了，符合{stage}学段学生的理解水平
- 题目内容必须与单元内容相关，体现单元知识点

**示例**：
```json
{
  "stem": {
    "text": "请写出'春天'的反义词。"
  },
  "resources": []
}
```

---

### 3.2 图片资源（image）
**适用场景**：看图写词、看图说话、看图计算等

**生成要求**：
- 题干使用 `stem.text` 描述题目要求
- 在 `resources` 中添加图片资源，`resource_type` 为 `"stem"`，`type` 为 `"image"`
- **必须生成 `image_prompt` 字段**，用于图片生成的提示词
- `image_prompt` 要求：
  - 简洁清晰，适合{stage}学段学生认知水平
  - 使用卡通、插画风格，避免写实风格
  - 明确指定背景（如"纯色背景"、"简单背景"、"白色背景"）
  - 明确指定颜色（如"鲜艳的颜色"、"明亮的颜色"）
  - 主要对象清晰可见，避免复杂背景和过多细节
  - 图片内容应与单元内容相关，体现单元知识点

**示例**：
```json
{
  "stem": {
    "text": "看图，写出图片中动物的名称。"
  },
  "resources": [
    {
      "id": "stem_image_1",
      "resource_type": "stem",
      "type": "image",
      "image_prompt": "一只可爱的小猫，卡通风格，白色背景，色彩鲜艳，简单清晰"
    }
  ]
}
```

**图片提示词示例**：
- 看图写词：`"一个红色的苹果，卡通风格，白色背景，色彩鲜艳，简单清晰"`
- 看图计算：`"3个苹果和2个香蕉放在桌子上，卡通风格，简单背景，物品清晰可数"`
- 看图说话：`"小朋友在公园里玩耍，卡通风格，明亮背景，场景简单，人物清晰"`

### 3.3 音频资源（audio）
**适用场景**：听音写词、听音填空、听音回答等

**生成要求**：
- 题干使用 `stem.text` 描述题目要求（如"听录音，写出你听到的单词"）
- 在 `resources` 中添加音频资源，`resource_type` 为 `"stem"`，`type` 为 `"audio"`
- **必须生成 `text` 字段**，用于TTS语音合成的文本内容
- `text` 要求：
  - 发音清晰，适合{stage}学段学生
  - 语速适中，句子长度合理
  - 低学段：单词或短语，≤5个词
  - 中学段：简单句子，≤8个词
  - 高学段：完整句子，≤12个词
  - 音频内容应与单元内容相关，体现单元知识点

**示例**：
```json
{
  "stem": {
    "text": "听录音，写出你听到的单词。"
  },
  "resources": [
    {
      "id": "stem_audio_1",
      "resource_type": "stem",
      "type": "audio",
      "text": "apple"
    }
  ]
}
```

**音频文本示例**：
- 听音写词：`"apple"`、`"book"`、`"school"`
- 听音填空：`"I like apples"`（句子中某个词需要填空）
- 听音回答：`"What color is the apple?"`（需要学生回答）

## 四、答案配置

### 4.1 答案类型
输入题通常使用 `fuzzy`（模糊匹配）或 `exact`（精确匹配）类型：

- **精确匹配（exact）**：适用于有唯一标准答案的题目
  - 示例：计算题、单词拼写、固定答案
  ```json
  {
    "answer": {
      "type": "exact",
      "correct_answers": ["5"]
    }
  }
  ```

- **模糊匹配（fuzzy）**：适用于有多种表达方式的答案
  - 示例：简答题、开放性问题、同义词答案
  ```json
  {
    "answer": {
      "type": "fuzzy",
      "correct_answers": ["冬天", "冬季"],
      "accept_answers": ["冬", "寒冷的季节"]
    }
  }
  ```

### 4.2 答案格式要求
- 数字答案：直接写数字，如 `"5"`、`"3.14"`
- 文字答案：使用标准表达，如 `"苹果"`、`"春天"`
- 多个答案：使用数组，如 `["答案1", "答案2"]`
- **答案必须与单元内容相关**，体现单元知识点

## 五、学段适配要求

### 5.1 低学段
- **文字**：使用简单词汇，句子简短（≤10字）
- **图片**：内容简单，色彩鲜明，避免复杂细节
- **音频**：单词或短语，发音清晰，语速慢
- **题目难度**：基础知识点，注重识记和理解

### 5.2 中学段
- **文字**：使用常用词汇，句子完整（≤20字）
- **图片**：可以包含简单场景，2-3个关键元素
- **音频**：简单句子，语速适中
- **题目难度**：中等难度，注重应用和分析

### 5.3 高学段
- **文字**：可以使用较复杂表达，句子完整（≤30字）
- **图片**：可以包含较复杂场景，多个元素
- **音频**：完整句子，语速正常
- **题目难度**：较高难度，注重综合和评价

## 七、输出格式要求

{format_instructions}

**重要字段说明**：
- `stem.text`：题干文本，必填，必须与单元内容相关
- `resources`：资源列表，根据题目需要添加（**仅支持图片和音频两种类型**）
  - `resource_type`：必须为 `"stem"`（题干资源）
  - `type`：资源类型，仅可选 `"image"` 或 `"audio"`（**不支持视频、动画或复合资源**）
  - `image_prompt`：图片资源必填，用于图片生成，内容需与单元相关
  - `text`：音频资源必填，用于TTS语音合成，内容需与单元相关
- `answer`：答案配置，必填
  - `type`：答案类型，通常为 `"exact"` 或 `"fuzzy"`
  - `correct_answers`：正确答案列表
  - `accept_answers`：可接受的答案列表（模糊匹配时使用）
- `explanation`：题目解析，建议填写，需说明与单元知识点的关联
- `difficulty`：题目难度，可选 `"easy"`、`"medium"`、`"hard"`
- `knowledge_points`：知识点列表，建议填写，需与单元内容对应
