# 学生应用分级配色规范

本文档定义了针对低、中、高三个年级段的 UI 配色和风格规范。基于现有的 Tailwind CSS + shadcn/ui 架构，通过调整 CSS 变量来实现不同年级的界面风格切换。

## 1. 低年级（1-2年级）：快乐乐园 (Joyful Land)

针对 6-8 岁儿童。设计风格需要高饱和度、暖色调、大圆角，强调趣味性和亲和力，以此吸引注意力并降低学习的枯燥感。

### 设计理念
*   **色彩心理**：使用类似于玩具的糖果色。
*   **对比度**：高对比度，但背景保持柔和，避免刺眼。
*   **形状**：大圆角 (Large Radius)，给人安全、柔软的感觉。

### 配色方案 (CSS Variables)

```css
/* Theme: Low Grade (Grade 1-2) */
:root {
  /* 主色：明亮的天空蓝/糖果蓝，充满活力 */
  --primary: 210 90% 60%;
  --primary-foreground: 0 0% 100%;

  /* 辅助色：淡奶油色/柔和的暖白，用于次级背景，营造温馨感 */
  --secondary: 45 100% 96%;
  --secondary-foreground: 25 90% 45%;

  /* 强调色：鲜艳的太阳黄/橙，用于奖励和重点提示 */
  --accent: 35 95% 60%;
  --accent-foreground: 0 0% 100%;

  /* 破坏/警告色：柔和的红/粉红，避免过于惊吓 */
  --destructive: 0 80% 65%;
  --destructive-foreground: 0 0% 100%;

  /* 背景：纯白或极淡的暖调白 */
  --background: 0 0% 100%;
  --foreground: 222 47% 15%; /* 深蓝黑文字，比纯黑更柔和 */

  /* 卡片：白色，带暖色阴影（阴影在 CSS 中另设，此处为底色） */
  --card: 0 0% 100%;
  --card-foreground: 222 47% 15%;

  /* 边框：较粗的柔和色边框 */
  --border: 210 40% 90%;
  --input: 210 40% 90%;
  --ring: 210 90% 60%;

  /* 圆角：非常圆润 */
  --radius: 1rem; /* 16px - 24px */
}
```

## 2. 中年级（3-4年级）：探索世界 (Adventure World)

针对 9-10 岁儿童。设计风格开始向标准化过渡，颜色保持明快但降低了饱和度，增加了一些秩序感和探索感。

### 设计理念
*   **色彩心理**：自然色系（森林绿、海洋蓝），象征成长和探索。
*   **对比度**：适中，注重阅读体验。
*   **形状**：中等圆角，既不幼稚也不过于死板。

### 配色方案 (CSS Variables)

```css
/* Theme: Middle Grade (Grade 3-4) */
:root {
  /* 主色：翡翠绿/蓝绿色，象征成长与平静 */
  --primary: 160 84% 39%;
  --primary-foreground: 0 0% 100%;

  /* 辅助色：淡薄荷绿/灰绿，清爽护眼 */
  --secondary: 150 30% 96%;
  --secondary-foreground: 160 40% 20%;

  /* 强调色：珊瑚红/橙红，用于行动点 */
  --accent: 12 85% 65%;
  --accent-foreground: 0 0% 100%;

  /* 破坏/警告色：标准红 */
  --destructive: 0 84% 60%;
  --destructive-foreground: 0 0% 100%;

  /* 背景：冷调白或灰白 */
  --background: 0 0% 100%;
  --foreground: 215 25% 15%;

  --card: 0 0% 100%;
  --card-foreground: 215 25% 15%;

  --border: 160 20% 90%;
  --input: 160 20% 90%;
  --ring: 160 84% 39%;

  /* 圆角：适中 */
  --radius: 0.75rem; /* 12px */
}
```

## 3. 高年级（5-6年级）：专注学堂 (Focus Studio)

针对 11-12 岁少年。设计风格接近成人应用，极简、干净、科技感，强调效率和专注，减少干扰元素。

### 设计理念
*   **色彩心理**：智慧蓝、深紫、高级灰。体现专业感和沉稳。
*   **对比度**：高对比度的文字，低对比度的背景装饰。
*   **形状**：小圆角或直角，显得干练。

### 配色方案 (CSS Variables)

```css
/* Theme: High Grade (Grade 5-6) */
:root {
  /* 主色：经典的科技蓝/靛蓝，专业、专注 */
  --primary: 220 80% 50%; /* 或者使用当前代码中的紫色 262 83% 58% */
  --primary-foreground: 0 0% 100%;

  /* 辅助色：冷灰色，极简 */
  --secondary: 210 20% 96%;
  --secondary-foreground: 222 47% 11%;

  /* 强调色：电光紫或青色，用于高亮关键信息 */
  --accent: 262 80% 60%;
  --accent-foreground: 0 0% 100%;

  /* 破坏/警告色：深红 */
  --destructive: 0 70% 50%;
  --destructive-foreground: 0 0% 100%;

  /* 背景：纯净的冷白 */
  --background: 0 0% 100%;
  --foreground: 222 47% 10%;

  --card: 0 0% 100%;
  --card-foreground: 222 47% 10%;

  --border: 220 13% 91%;
  --input: 220 13% 91%;
  --ring: 220 80% 50%;

  /* 圆角：精致小圆角 */
  --radius: 0.5rem; /* 8px */
}
```

## 实现建议

1.  **动态切换**：
    可以通过在 `<body>` 或应用根节点添加 `data-grade="low" | "middle" | "high"` 属性，然后在全局 CSS 中使用属性选择器来覆盖变量。

    ```css
    /* 默认 (可以设为其中一种，例如低年级) */
    :root { ... }

    /* 低年级覆盖 */
    [data-grade="low"] {
       --primary: 210 90% 60%;
       /* ...其他变量 */
       --radius: 1rem;
    }

    /* 中年级覆盖 */
    [data-grade="middle"] {
       --primary: 160 84% 39%;
       /* ...其他变量 */
       --radius: 0.75rem;
    }

    /* 高年级覆盖 */
    [data-grade="high"] {
       --primary: 220 80% 50%;
       /* ...其他变量 */
       --radius: 0.5rem;
    }
    ```

2.  **暗色模式适配**：
    上述配色主要针对亮色模式。对于学生应用，建议主要优化亮色模式的阅读体验。若需支持暗色模式，需为每个年级段单独调整其 Dark Mode 下的饱和度和亮度，避免高饱和度颜色在黑底上产生视觉残像。
