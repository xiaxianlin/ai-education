# 一年级 

## 英语

- 选择题
    - 看图选词，看到一张图片（例如，苹果），选择最符合图片内容的单词
    - 看图选句，看到一张图片（例如，一个孩子在奔跑），选择最符合图片内容的句子
    - 听音选词，听一段录音（录音播放的单词），从多个选项中选择正确的单词
    - 听音选句，听一段录音（录音播放的句子），从多个选项中选择正确的句子
    - 情景问答，根据给出的问句或情景，选择最恰当的答语
    - 句型填空，句子中缺少一个单词，选择最合适的词填入
    - 词序重组，给出打乱顺序的几个单词，选择正确排列的句子
- 拼写题
    - 听音写单词，听录音播放一个简单且常用的单词，孩子根据发音拼写出整个单词
    - 看图写单词，看到一张图片，孩子写出图片所示事物的英文名称
    - 单词重组，给出打乱顺序的单词字母，要求孩子重新排列，拼写出正确的单词
    - 单词翻译，根据中文词汇或英文单词，要求孩子写出英文拼写或中文词汇
- 口语题：
    - 录音跟读
        - 单词精准模仿，播放一个核心单词，孩子录音跟读，系统对比发音的准确度和流利度，给出得分。
        - 句子情绪模仿，播放一段对话录音，要求孩子模仿发音、语调和情感（例如，惊讶或开心）。
        - 朗读小挑战，平台展示一段 3-5 句的简单文本（如儿歌或绕口令），让孩子朗读。
    - 情景问答
        - 听问题口头回答，平台播放一个简单问题，孩子通过麦克风给出口头答案。系统尝试识别答案的关键词（如 I′m six）。
        - 看图口头描述，屏幕展示一张简单的图画（例如：一个绿色的青蛙），要求孩子用一句话描述。
        - 角色扮演对话，孩子和虚拟角色（如动画人物）进行对话。平台播放 A 的台词，孩子扮演 B 说出台词。

## 数学

- 选择题
    - 快速口算，屏幕显示 13−5= ?，下方给出 A (7), B (8), C (9) 三个选项。孩子点击正确答案。
    - 数位判断，屏幕显示数字 17，提问：“7 在哪个数位上？” 选项：A. 十位 B. 个位 C. 百位。
    - 图形归类，提问：“下面哪个图形是正方形？” 选项：A, B, C 各是一个不同的图形图片。
- 填空题
    - 键盘输入计算，屏幕显示算式 8+6= □ 或 14−□=6，孩子通过虚拟数字键盘输入答案。	
    - 规律填数，屏幕显示一串数字 2,4,6,(  ),10，孩子输入缺失的数字。
    - 组成与分解，屏幕显示 10 个一组成 (□)，或者 1 个十和 8 个一组成 (□)。
- 识图题
    - 看图列式，屏幕播放动画：5 个苹果，飞来 3 个苹果。要求孩子在下方点击数字和符号 □+□=□ 完成算式。
    - 数图形，屏幕显示一个由三角形和长方形组成的复杂图案。让孩子点击并统计图形的数量。
    - 数位看图，屏幕显示小棒图：一捆小棒和几根散小棒。让孩子在下方输入对应的两位数。
- 排序题
    - 数字大小排序，给出三张数字卡片 19,5,12，要求孩子按从大到小的顺序拖拽到指定框内。
    - 算式结果排序，给出三个算式（如 5+5,12−3,9+6），要求孩子计算后按结果从小到大拖拽算式卡片。	
    - 序数排列，给出 First（第一）, Third（第三）等卡片，要求孩子按照顺序排列。
- 匹配题
    - 算式与结果匹配，左侧列出算式 10−4,5+7；右侧列出得数 6,12。孩子通过拖拽连线进行匹配。	
    - 时钟与时间匹配，左侧列出钟面（指针指着整点）；右侧列出文字或数字时间（如 3 点）。孩子连线匹配。
    - 符号与概念匹配，左侧是符号 >,<,=；右侧是两组数字 5 8,10 10。孩子拖拽符号到中间的 □ 中。
