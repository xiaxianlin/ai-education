# K12 学科学习与练习平台 - 技术文档

## 一、架构概览

- 前端：React + TailwindCSS / Vue3
- 后端：FastAPI（Python）
- 数据库：PostgreSQL
- 缓存层：Redis
- 任务队列：Celery（审核、推荐生成等）
- 文件存储：OSS (图像/语音)
- AI 接口：OpenAI / 阿里云语音服务（ASR + TTS）

---

## 二、模块设计说明

### 1. AI 题目生成模块

- 输入：教材段落文本
- 调用大语言模型（如 GPT）生成选择题、填空题、阅读理解题
- 输出：题干、选项、正确答案、解析

**Prompt 示例：**
```
你是一名小学数学教研专家。请根据下列教材内容，为五年级学生生成3道与“分数加减法”相关的选择题。每道题应包含题干、4个选项（A-D）、正确答案和详细解析。
教材内容如下：
[教材原文]
```

---

### 2. 题目审核模块

- 自动审核：检查语义逻辑、格式、答案一致性
- 人工审核：任务流支持“待审阅”、“通过”、“修改”、“退回”等状态

---

### 3. 推荐系统模块

- 协同过滤获取题目候选
- 内容过滤匹配知识点 + 难度
- LightGBM 评分预测答题正确率，排序后返回推荐列表

**推荐伪代码：**
```python
def recommend_questions(student_id, top_k=20):
    history = load_history(student_id)
    similar_students = find_similar_students(student_id)
    cf_set = recommend_by_cf(similar_students)
    content_set = recommend_by_content(history)
    merged = merge(cf_set, content_set)
    scored = [(q, model.predict(features(student_id, q))) for q in merged]
    return sorted(scored, key=lambda x: x[1], reverse=True)[:top_k]
```

---

### 4. 英语口语评测模块

- ASR：识别学生录音内容（Aliyun 语音识别）
- TTS：播放标准句音频
- 打分维度：准确度、流利度、完整度
- 结果结构：
```json
{
  "ref": "This is my pencil.",
  "hyp": "Dis is my pencil.",
  "score": {
    "accuracy": 72,
    "fluency": 85,
    "completeness": 90
  },
  "advice": "注意 th 发音，pencil 尾音更清晰"
}
```

## 三、数据库结构概览

- 用户表：user
- 题目表：question（题干、答案、知识点、难度）
- 错题记录表：wrong_question
- 推荐记录表：recommend_log
- 答题记录表：answer_record
- 口语评测表：oral_result
