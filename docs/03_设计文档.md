# K12 学科学习与练习平台 - 设计文档

## 一、设计系统概览

### 色彩系统

| 名称           | HEX      | 用途 |
|----------------|----------|------|
| PrimaryBlue    | #2F80ED  | 主色（数学） |
| PrimaryGreen   | #27AE60  | 主色（英语） |
| ErrorRed       | #EB5757  | 错误标记 |
| SuccessGreen   | #219653  | 成功提示 |
| BackgroundGray | #F5F7FA  | 背景色 |

### 字体规范

- 字体：思源黑体 / PingFang SC
- H1：24px Bold
- H2：20px Semibold
- Body：16px Regular
- Button：14px Medium

---

## 二、UI 组件规范（Figma）

### 按钮（Button）

- 高度：40px，圆角：8px
- 类型：主按钮、次按钮、禁用态
- 状态：默认 / Hover / Disabled

### 输入框（Input）

- 高度40px，圆角6px，边框灰色
- 聚焦时主色加粗，错误状态红边框
- 支持提示语与错误信息显示

### 卡片（Card）

- 白底，圆角8px，阴影 subtle
- 类型：练习题卡、错题卡、统计卡片

---

## 三、交互动画说明

- 页面切换：滑动淡入（0.3s）
- 按钮点击：轻微缩放 + 阴影
- 成绩图表：雷达图 / 饼图动态填充（0.8s）
- 录音反馈：录音波形实时渲染

---

## 四、AI Prompt 模板汇总

### 题目生成（数学）：
```
请为以下小学五年级数学教材内容生成3道选择题，难度适中，包含答案和解析：
[教材内容]
```

### 英语口语评分：
```
你是一名英语发音评分助手，请对以下学生录音文本与标准句进行对比，给出准确度、流利度、完整度评分，并提供建议。
标准句："Where is my schoolbag?"
识别结果："Where is my schoolbug?"
```
