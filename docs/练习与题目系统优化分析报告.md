## 二、文档需求与当前实现的对比分析

### 2.1 题型设计需求

根据文档，小学低年级（1-2年级）共设计了 **135 种题型**：

| 学科 | 年级 | 题型数量 | 场景分布 |
|------|------|---------|---------|
| 语文 | 1-2年级 | 15种/年级 × 2年级 = 30种 | 选择题、填空题、判断题、连线题 |
| 数学 | 1-2年级 | 15种/年级 × 2年级 = 30种 | 选择题、填空题、判断题、计算题 |
| 英语 | 1-2年级 | 15种/年级 × 2年级 = 30种 | 选择题、填空题、判断题、连线题 |

**题型特征**：
- 每种题型包含：`title`、`scene`、`subject`、`grade`、`description`、`resource_type`、`prompt`
- 资源类型包括：`image`（图片）、`audio`（语音）、无资源（纯文本）
- 每种题型都有详细的 AI 生成 Prompt

### 2.2 当前数据库模型支持情况

#### QuestionType 表（题型表）

## 三、练习会话流程分析

### 3.1 当前实现流程

#### 练习创建流程（`shared/practice/generate.py`）

```
1. 校验教材和练习是否存在
   ↓
2. 检查是否已存在同类型练习（daily/unit/assess）
   - 若存在，废弃旧会话（status=3）
   ↓
3. 创建 PracticeSession 记录（generate_status=1）
   ↓
4. 选择生成方式：
   - immediately=True: 同步生成
   - immediately=False: 异步任务队列（Celery）
   ↓
5. 执行题目生成工作流（LangGraph）
   ↓
6. 创建答题记录（PracticeSessionAnswer）
   ↓
7. 更新会话状态（generate_status=2）
```

**✅ 优点**：
- 支持同步和异步两种生成方式
- 使用 LangGraph 构建清晰的工作流
- 自动废弃旧练习，避免冲突
- 预创建答题记录，优化查询性能

**⚠️ 待优化点**：
1. **缺少重试机制**：题目生成失败时，没有自动重试
2. **缺少进度反馈**：异步生成时，前端无法获取生成进度
3. **缺少生成日志**：无法追踪题目生成的详细过程
4. **资源生成失败处理不足**：图片/语音生成失败时，题目仍然会被保存
5. **错误处理粗糙**：生成失败时直接删除会话，用户无法了解失败原因

### 3.2 题目生成工作流（`shared/generation/question/graph.py`）

**当前流程（LangGraph）**：
```
entry → load_data → build_prompt → call_llm → handle_resource → update_questions → END
```

**✅ 优点**：
- 使用 LangGraph 实现清晰的 DAG 流程
- 支持多种练习类型（daily/unit/assess）的路由
- 节点职责单一，易于维护和测试

**⚠️ 待优化点**：
1. **缺少题目去重机制**：可能生成与历史题目重复的内容
2. **缺少题目质量检查**：没有对生成的题目进行质量验证
3. **Prompt 模板化不足**：不同练习类型的 Prompt 构建逻辑重复
4. **缺少题目缓存**：相同的参数可能重复生成题目
5. **召回题目策略简单**：`recall_questions` 逻辑不够灵活

**优化建议**：

1. **添加题目去重节点**：
```python
async def deduplicate_questions_node(state: QuestionGenerationState):
    """题目去重：检查生成题目是否与题库重复"""
    db = state["db"]
    generated_questions = state["generated_questions"]

    # 计算题目指纹
    for q in generated_questions:
        q.fingerprint = calculate_question_fingerprint(q)

    # 查询题库中是否有相似题目
    existing_fingerprints = await db.scalars(
        select(Question.fingerprint).where(
            Question.fingerprint.in_([q.fingerprint for q in generated_questions])
        )
    )

    # 过滤重复题目
    unique_questions = [q for q in generated_questions if q.fingerprint not in existing_fingerprints]

    logger.info(f"题目去重: 原始={len(generated_questions)}, 去重后={len(unique_questions)}")
    return {"generated_questions": unique_questions}
```

2. **添加题目质量检查节点**：
```python
async def validate_questions_node(state: QuestionGenerationState):
    """题目质量检查"""
    questions = state["generated_questions"]
    validated_questions = []

    for q in questions:
        # 检查必填字段
        if not q.content or not q.answer:
            logger.warning(f"题目字段缺失: question_id={q.id}")
            continue

        # 检查选项格式
        if q.options and len(q.options) < 2:
            logger.warning(f"选项数量不足: question_id={q.id}")
            continue

        # 检查答案在选项中
        if q.options and q.answer not in [opt["key"] for opt in q.options]:
            logger.warning(f"答案不在选项中: question_id={q.id}")
            continue

        validated_questions.append(q)

    return {"generated_questions": validated_questions}
```

3. **添加学习轨迹分析**：
```python
async def analyze_learning_trajectory(db: AsyncSession, student_id: str, knowledge: str):
    """
    分析学生对某知识点的学习轨迹
    """
    # 查询历史练习记录
    history = await db.scalars(
        select(PracticeSessionAnswer)
        .join(Question)
        .where(
            PracticeSessionAnswer.student_id == student_id,
            Question.knowledge == knowledge
        )
        .order_by(PracticeSessionAnswer.submit_time)
    ).all()

    # 计算移动平均正确率
    window = 5
    moving_accuracy = []
    for i in range(window, len(history)):
        recent = history[i-window:i]
        accuracy = sum(1 for a in recent if a.status == 1) / window
        moving_accuracy.append({
            "date": recent[-1].submit_time,
            "accuracy": accuracy
        })

    # 判断趋势
    if len(moving_accuracy) >= 2:
        trend = "上升" if moving_accuracy[-1]["accuracy"] > moving_accuracy[0]["accuracy"] else "下降"
    else:
        trend = "数据不足"

    return {
        "moving_accuracy": moving_accuracy,
        "trend": trend,
        "total_attempts": len(history)
    }
```

## 五、数据一致性与性能优化

### 5.1 数据冗余与一致性

**当前设计**：
- `PracticeSessionAnswer` 表中冗余存储了 `unit_id`、`knowledge`、`textbook_id`
- `PracticeSession.parameters` 中以 JSON 格式存储参数

**✅ 优点**：
- 减少关联查询，提升查询性能
- 历史数据不受教材、知识点更新影响

**⚠️ 风险点**：
1. **数据不一致**：冗余字段可能与源表数据不一致
2. **更新复杂**：题目信息变更时需要同步更新冗余字段
3. **存储浪费**：JSON 字段可能存储重复信息

**优化建议**：

1. **定期数据一致性检查**：
```python
async def check_data_consistency(db: AsyncSession):
    """检查数据一致性"""
    # 检查 PracticeSessionAnswer 中的冗余字段
    answers = await db.scalars(select(PracticeSessionAnswer)).all()

    inconsistent_count = 0
    for answer in answers:
        question = await db.scalar(select(Question).where(Question.id == answer.question_id))
        if question:
            if answer.unit_id != question.unit_id:
                logger.warning(f"unit_id 不一致: answer_id={answer.id}")
                inconsistent_count += 1
            if answer.knowledge != question.knowledge:
                logger.warning(f"knowledge 不一致: answer_id={answer.id}")
                inconsistent_count += 1

    logger.info(f"数据一致性检查完成，发现 {inconsistent_count} 条不一致记录")
```

async def recommend_next_question(
    db: AsyncSession,
    student_id: str,
    subject: str,
    grade: int,
    current_ability: float
) -> Question:
    """
    基于学生能力值推荐下一道题
    - 选择难度与学生能力匹配的题目
    - 优先推荐薄弱知识点
    - 避免最近已做过的题目
    """
    # 计算目标题目难度
    # 能力值与题目难度映射：theta -> difficulty
    if current_ability > 1.5:
        target_difficulty = "困难"
    elif current_ability > 0:
        target_difficulty = "普通"
    else:
        target_difficulty = "简单"

    # 查询薄弱知识点
    weak_knowledges = await get_weak_knowledges(db, student_id, subject, grade)

    # 查询最近做过的题目ID
    recent_question_ids = await get_recent_questions(db, student_id, days=7, limit=50)

    # 推荐题目
    question = await db.scalar(
        select(Question)
        .where(
            Question.subject == subject,
            Question.grade == grade,
            Question.difficulty == target_difficulty,
            Question.knowledge.in_(weak_knowledges),
            Question.id.notin_(recent_question_ids)
        )
        .order_by(func.random())  # 随机选择
    )

    return question
