
# 🧠 ChatGPT 自动出题 Prompt 模板（数学与英语）

以下为适用于 K12 出题系统的 ChatGPT Prompt 模板，覆盖数学与英语多个题型。

---

## 📐 数学出题 Prompt 模板

### 🧮 模板 1：小学数学 · 填空题
```
你是小学数学老师，请帮我命制一道【小学五年级】【整数乘除法】相关的【填空题】。

要求如下：
- 题目真实，贴近生活。
- 不能太简单，应包含运算顺序或单位换算。
- 给出答案与详细解析。

请以 JSON 格式输出：
{
  "grade": "五年级",
  "type": "填空题",
  "knowledge_point": "整数乘法与除法",
  "question": "...",
  "answer": "...",
  "explanation": "..."
}
```

### 📐 模板 2：初中数学 · 选择题（几何）
```
请为【初一学生】出一道关于【三角形全等判定】的【单选题】。

要求：
- 题目带图形描述或文字描述
- 设置4个选项（其中一个为正确答案）
- 提供标准答案和解析说明

输出格式：
{
  "grade": "七年级",
  "type": "单选题",
  "question": "...",
  "options": ["A...", "B...", "C...", "D..."],
  "answer": "B",
  "explanation": "..."
}
```

## 📘 英语出题 Prompt 模板

### 📙 模板 1：小学英语语法题（一般现在时）
```
请设计一道【小学六年级英语】的一般现在时语法单选题。

要求：
- 句子要自然
- 设置 4 个干扰项
- 提供标准答案与解释

输出格式：
{
  "grade": "Grade 6",
  "type": "单选题",
  "question": "She ___ to school every day.",
  "options": ["go", "goes", "gone", "going"],
  "answer": "goes",
  "explanation": "主语是 She，第三人称单数，因此用 goes。"
}
```

### 📙 模板 2：英语阅读理解题
```
请为【初中一年级英语】设计一个小阅读理解。

要求：
- 一段50字以内的小短文
- 两个问题，每题有3个选项
- 提供答案与解释

输出格式：
{
  "grade": "Grade 7",
  "type": "阅读理解",
  "passage": "...",
  "questions": [
    {
      "q": "...",
      "options": ["A...", "B...", "C..."],
      "answer": "A",
      "explanation": "..."
    },
    ...
  ]
}
```

---

## ✨ 提升质量的技巧

- 在 prompt 中加上“贴近真实生活”、“避免重复题型”、“参考中考题型风格”等要求；
- 引导模型“先生成知识点 → 再出题”，提升精准度；
- 对于复杂题型（如阅读理解），建议分步生成（先生成文章，再出题）；
- 明确格式要求为 JSON，方便系统解析处理。
