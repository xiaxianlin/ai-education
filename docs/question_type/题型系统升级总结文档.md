# 题型系统升级总结文档

本次变更对题型（QuestionType）与题目（Question）系统进行了深度重构，确立了“能力训练”与“单元练习”的双轨制架构，并大幅优化了数据结构的灵活性与可扩展性。

## 1. 核心模型重构

### QuestionType (题型配置)

-   **分类属性**：新增 `category` (能力/单元) 和 `grade_band` (学段)。
-   **配置聚合**：将零散的交互与评估字段整合为三大 JSON 对象：
    -   `media_context`: 定义支持的媒体类型(文本/图片/音视频)及其配置。
    -   `scaffolding_config`: 定义脚手架模式(单/多选)与交互工具(提示/模板)。
    -   `evaluation_config`: 聚合评估模式(`auto_match`/`ai_analysis`)、正确答案参考及评分量表。
-   **关联清理**：新增 `ability_code` 直接关联原子能力，清理了 15 个冗余字段。

### Question (题目内容)

-   **内容聚合**：新增 `content` JSON 字段，整合了原有的题干、选项、资源、子题等结构。
-   **能力打标**：直接存储 `ability_code`，便于跨维度查询。
-   **关联优化**：题目与题型的关联由 ID 切换为 `question_type_code`，增强了数据的可读性与可迁移性。

## 2. Pydantic Schema 强类型化

为了确保前后端对接的严谨性，对所有 JSON 字段构建了强类型的 Schema 定义：

-   **[ResourceSchema](file:///Users/xiaxianlin/projects/ai-education/apps/server/shared/core/schema/question.py)**: 统一的资源定义（含 URL 和 Alt）。
-   **[ContentSchema](file:///Users/xiaxianlin/projects/ai-education/apps/server/shared/core/schema/question.py)**: 支持多层级嵌套，适配复合题结构。
-   **清理冗余**：删除了 `StemSchema`, `SubQuestionSchema`, `FeedbackConfigSchema` 等 7 个已废弃的定义。

## 3. 题型预置数据定义

创建了 [import_question_types.py](file:///Users/xiaxianlin/projects/ai-education/apps/server/scripts/import_question_types.py) 脚本，预定义了 **42 个** 标准题型：

-   **单元练习 (5 个)**: 选择、填空、判断、匹配、排序。
-   **语文能力 (14 个)**: 涵盖拼音、识字、阅读理解等。
-   **英语能力 (11 个)**: 涵盖听力、词汇、句法等。
-   **数学能力 (12 个)**: 涵盖数感、几何、逻辑推理等。
