# K12 学科练习系统｜线框图要点

## 信息架构
- 底部主导航采用四栏：`首页`、`错题集`、`练习记录`、`我的`；顶部保留头像与语音助手入口，减少层级跳转。
- 主任务流：`首页 → 每日练习 → 完成反馈 → 推荐再练/错题集`，保证练习闭环。

## 首页 / 今日练习
- 目标：突出每日练习入口，露出单元练习与能力评测快捷卡片。
- 核心布局：顶部问候 + 勋章进度 → 今日任务卡（进度环 + 主按钮“开始每日练习”）→ 单元练习大卡 → 能力评测卡 → 成就/榜单滚动条。
- 关键交互：主按钮支持继续状态；卡片“看讲解”直达错题；语音按钮提供任务说明。
- 适龄要点：卡通头像、星星奖励、图文结合卡片、语音提示降低阅读负担。

## 每日练习题目页
- 目标：2 步内开题，兼容识图与跟读题型。
- 核心布局：顶部进度条 + 激励提示 → 大字体题干（含图片放大/听题按钮）→ 答案区（大尺寸按钮或录音控件）→ 底部操作（上一题/提交/跳过）。
- 关键交互：作答即时反馈动画；跟读题录音后即时评分和表情反馈。
- 适龄要点：触控目标≥48px；跟读题配口型示范；错误提示语言积极。

## 每日练习完成页
- 目标：形成即时反馈，展示正确率与错因分类。
- 核心布局：完成动画 → 成绩卡（正确率、用时、星星奖励）→ 错因分类卡 + “一键再练” → 推荐卡（补练包/单元练习/评测）→ 分享/家长通知入口（可灰化）。
- 关键交互：错因卡直链错题详情；系统基于掌握度推荐下一步。
- 适龄要点：表扬文案 + 语音讲解；提供“稍后再练”缓冲。

## 单元练习
- 目标：按教材单元选择练习，完成后展示掌握度。
- 入口布局：科目标签（数学/英语）→ 单元卡片（名称、知识点标签、开始按钮）→ 底部悬浮进度提示。
- 报告布局：单元标题 + 动画 → 雷达图 + 文本解释 → 知识点列表（正确率、题数、“去再练”）→ 建议卡片。
- 适龄要点：雷达图配表情标签；知识点描述生活化。

## 错题集
- 目标：自动归档并支持筛选、再练。
- 布局：顶部错题统计 + 今日复习数 → 筛选条（知识点/题型/时间）→ 错题卡列表（题干缩略 + “再练”按钮，右滑标记掌握）→ 底部“一键生成错题包”。
- 关键交互：错题详情支持语音/图片解析，错题包倒计时激励。
- 适龄要点：科目配色区分；解析语音按钮明显。

## 能力评测
- 入口布局：邀请横幅（奖励说明）→ 信息卡（题量/预计时间/奖励）→ “开始评测”主按钮 + 情绪缓解按钮。
- 报告布局：等级徽章 + 对比提示 → 雷达图（刻度解释）→ 薄弱点列表（建议练习）→ 分享/导出按钮。
- 适龄要点：报告拆页（图表/建议），每部分配语音讲解。

## 练习记录
- 目标：按时间线呈现每日练习，支持回看成绩与错题。
- 布局：顶部周视图（完成日高亮）→ 时间轴卡片（日期、科目、用时、正确率、“查看详情”）→ 底部坚持天数与连练奖励提示。
- 适龄要点：盖章式奖励、语音回顾“老师建议”。

## 通用设计要点
- 增设语音、动画引导，关键操作旁提供语音按钮，完成时触发角色动画。
- 在各模块标注预计时间，帮助控制每日 20 分钟学习目标。
- 按合规要求，在完成页或长时停留弹出温和防沉迷提醒。
