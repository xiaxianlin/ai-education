# 📚 K12 教育题库设计文档模板 + 自动出题模板（数学 & 英语）

## 一、题库设计总纲

### 1.1 学科范围

* 数学
* 英语

### 1.2 年级覆盖

* 小学四年级至初三（可拓展）

### 1.3 题型支持

* 单选题、填空题、判断题、应用题（数学）
* 单选题、完形填空、阅读理解、改错题、写作题（英语）

### 1.4 标签结构设计

每道题应具备以下元信息：

```json
{
  "id": "uuid",
  "subject": "Math",
  "grade": "Grade 6",
  "skill": "Addition with carry",
  "type": "填空题",
  "difficulty": "easy",
  "source": "template",
  "tags": ["加法", "整数", "计算"]
}
```

## 二、出题模板设计

### 2.1 数学模板示例

#### 模板 1：整数加法（填空题）

```json
{
    "type": "填空题",
    "template": "计算：${a} + ${b} = ___",
    "params": {
        "a": [10, 100],
        "b": [10, 100]
    },
    "answer": "${a + b}"
}
```

#### 模板 2：长方形面积（填空题）

```json
{
    "type": "填空题",
    "template": "一个长方形长 ${l} 厘米，宽 ${w} 厘米，它的面积是 ___ 平方厘米。",
    "params": {
        "l": [2, 20],
        "w": [2, 20]
    },
    "answer": "${l * w}"
}
```

#### 模板 3：判断题

```json
{
    "type": "判断题",
    "template": "判断：${a} 是奇数。 (对/错)",
    "params": {
        "a": [1, 100]
    },
    "answer": "${a % 2 === 1 ? '对' : '错'}"
}
```

---

### 2.2 英语模板示例

#### 模板 1：一般现在时（单选题）

```json
{
    "type": "单选题",
    "template": "She ___ to school every day.",
    "options": ["go", "goes", "gone", "going"],
    "answer": "goes"
}
```

#### 模板 2：完形填空（填空题）

```json
{
    "type": "完形填空",
    "template": "I ___ (am/is/are) a student.",
    "options": ["am", "is", "are"],
    "answer": "am"
}
```

#### 模板 3：阅读理解（结构）

```json
{
    "type": "阅读理解",
    "passage": "Tom is a student. He likes apples and soccer. He goes to school by bike.",
    "questions": [
        {
            "q": "What does Tom like?",
            "options": ["Apples and soccer", "Soccer and school", "Bikes and apples"],
            "answer": "Apples and soccer"
        },
        {
            "q": "How does Tom go to school?",
            "options": ["By bus", "By bike", "By car"],
            "answer": "By bike"
        }
    ]
}
```

## 三、样题输出示例（基于模板生成）

### 数学样题

> **题型：填空题** > **题干**：一个长方形长 12 厘米，宽 5 厘米，它的面积是 \_\_\_ 平方厘米。
> **答案**：60

### 英语样题

> **题型：单选题** > **题干**：She \_\_\_ to school every day.
> **选项**：A. go B. goes C. gone D. going
> **答案**：B. goes

---

## 四、题库管理建议

-   使用 Airtable / SQLite / MongoDB 存储结构化题目
-   每个模板绑定多个样题（支持变式）
-   每道题应有：题干 + 答案 + 解析 + 元信息 + 标签
-   可设置“题目生成日志”与人工审核流程
