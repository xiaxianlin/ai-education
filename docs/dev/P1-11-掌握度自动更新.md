> **完成日期**: 2026-06-12 | **状态**: ✅ 已完成待审查

## 一、做了什么

学生完成练习后，自动根据答题结果更新对应能力点的掌握度（mastery_score、mastery_level、correct_count、wrong_count）。

此前掌握度数据仅靠手动/定时任务更新，现在改为：每次练习完成 → 即时触发累积计算 → 写入 `ah_student_ability_mastery` 表。

## 三、核心流程

```
学生完成练习 → Complete()
  ↓
1. 统计答案 → 报告生成（已有逻辑）
2. 调用 updateMasteryAfterComplete()（新增）
  ↓
updateMasteryAfterComplete():
  ├─ 获取练习数据（答案列表）
  ├─ 按能力点分组统计 correct / wrong
  ├─ 对每个能力点：
  │    ├─ 读取旧值（GetMastery）
  │    ├─ 累积加权平均计算新分数
  │    ├─ 计算掌握等级
  │    └─ UpsertMastery 写入
  └─ 失败仅 log，不影响主流程
```

### 累积算法

```
首次练习：
  score = 本次正确率 × 100
  total = 本次题数

后续练习：
  newScore = (oldScore × oldTotal + currentScore × currentTotal) / (oldTotal + currentTotal)
  total   = oldTotal + currentTotal
```

### 掌握等级分级

| 分数区间 | 等级 |
|---------|------|
| ≥ 80 | `mastered`（已掌握） |
| ≥ 60 | `proficient`（熟练） |
| ≥ 40 | `beginner`（入门） |
| < 40 | `unlearned`（未学习） |

## 五、关键设计决策

| 决策 | 理由 |
|------|------|
| `MasteryUpdater` 定义为独立接口（在 practice 包内） | 避免 practice → mastery 的直接包依赖，实现松耦合 |
| `WithMasteryUpdater()` 链式注入 | 不修改 `NewService` 签名，不破坏现有调用方 |
| 掌握度更新失败只 log warning | 不阻塞练习完成主流程，保证用户体验 |
| `Queryer` 接口扩展 `ExecContext` | `sql.DB` 和 `sql.Conn` 都已实现该方法，零侵入 |
| `BatchUpsertMastery` 逐条 upsert | 当前单次练习涉及的能力点 ≤ 10 个，无需批量优化 |
| 单元练习（unit_practice）暂复用 session.AbilityCode | 后续可通过题目关联能力点扩展 |

## 六、SQL 语句

```sql
INSERT INTO ah_student_ability_mastery
    (student_id, ability_code, mastery_score, mastery_level,
     correct_count, wrong_count, last_practice_time, update_time)
VALUES (?, ?, ?, ?, ?, ?, ?, UNIX_TIMESTAMP())
ON DUPLICATE KEY UPDATE
    mastery_score = VALUES(mastery_score),
    mastery_level = VALUES(mastery_level),
    correct_count = VALUES(correct_count),
    wrong_count = VALUES(wrong_count),
    last_practice_time = VALUES(last_practice_time),
    update_time = UNIX_TIMESTAMP()
```

## 七、待审查要点

1. **累积算法合理性**：加权平均是否满足业务需求？是否需要衰减因子？
2. **掌握等级阈值**：80/60/40 是否与前端展示一致？
3. **单元练习能力点映射**：当前 `resolveAbilityCode()` 对单元练习复用 session 级别 AbilityCode，是否需要改为题目级别？
4. **并发安全**：同一学生快速完成多个练习时，Get → 计算 Upsert 之间是否有竞态？（当前无事务保护）
