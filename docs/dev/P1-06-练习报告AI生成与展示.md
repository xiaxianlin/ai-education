## 三、核心流程

```
学生完成练习 → Complete()
  ↓
入队 report.generate 任务（非阻塞，失败只记日志）
  ↓
Worker 取出 → HandleReportGenerate()
  ↓
1. 获取会话 + 答题数据
2. 收集答案结果
3. 调 AI (Gemini) 生成报告
4. UpdateReport 写入 AI 字段
  ↓
前端拉取详情 → Model 层解析 JSON → 展示
```

## 五、关键设计决策

| 决策 | 理由 |
|------|------|
| `NewService` 用 variadic `...ReportGenerator` | 不破坏现有调用方 |
| 报告入队失败只记 warning | 不阻塞练习完成主流程 |
| 前端 Model 层解析 JSON | 组件拿到已解析的 typed 数据，不用到处 parse |
| AI 字段单独 `UpdateReport` | `CreateReport` 是创建时 upsert，AI 字段需要异步更新 |
