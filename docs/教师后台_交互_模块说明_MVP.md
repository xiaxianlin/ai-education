**教师后台交互文档 + 模块功能说明 + MVP 开发计划**

---

## 一、教师后台功能模块（交互与流程）

### 1. 教材上传与结构解析

* 页面入口：教材管理
* 支持上传教材 PDF / Word
* 显示解析结果结构树（章节、知识点）
* 教师可手动编辑章节结构、标注知识点

### 2. AI 题目生成器

* 页面入口：题库管理 → AI 出题
* 操作流程：

  1. 选择年级 → 学科 → 章节/知识点
  2. 设置题目数量、题型比例、难度
  3. 点击“生成题目” → 后台异步生成
  4. 查看生成结果（可编辑、删除、标记）

### 3. 题目审核与编辑

* 页面入口：题目审核
* 列表显示：题干预览、题型、章节、状态
* 支持筛选：未审/待审/通过/退回
* 点击题目：右侧弹出编辑器（可修改题干、选项、答案、解析等）
* 标注问题、建议改写、状态切换按钮

### 4. 作业布置与学生管理

* 页面入口：作业管理 / 学生学情
* 支持：

  * 按章节或自定义题组布置作业
  * 查看每位学生练习情况、正确率、耗时
  * 支持班级维度统计（薄弱知识点）

## 二、模块功能详细需求（FRD）

### 模块一：AI 题目生成器

* 输入：年级、学科、章节/知识点、题型需求
* 输出：结构化题目（含题干、选项、答案、解析）
* 系统功能：

  * 调用 GPT 模型接口
  * 输出质量控制（逻辑自检、敏感词过滤）
  * 可编辑题目草稿区，支持一键发布到题库

### 模块二：题目审核系统

* 功能：

  * 自动检测：空答案、无解析、重复选项、格式错误
  * 人工编辑器：富文本支持、Latex 数学公式、Markdown 支持
  * 审核流程：草稿 → 待审 → 已通过/退回

### 模块三：英语口语评测模块（教师端）

* 教师可上传英语句子，系统生成朗读+评分练习任务
* 查看学生朗读打分报告（流利度、准确度、完整度）
* 打分数据可视化（如打分趋势图）

### 模块四：学生学习报告

* 按班级、学生、时间、知识点维度查看
* 内容包括：完成率、正确率、平均用时、错题分布
* 可导出报告（PDF/Excel）

## 三、MVP 开发计划（阶段划分）

### 阶段一：基础平台搭建（1-2 周）

* 教师登录 / 教材上传 / 章节结构展示
* 手动创建章节 → 手动创建题目功能
* 学生练习模块基础版本（练题 + 答案 + 错题记录）

### 阶段二：AI 生成与审核系统（2-3 周）

* GPT 题目生成接口接入
* AI 题目审核器（规则 + 简易自检）
* 教师题库管理、题目编辑器上线

### 阶段三：作业与学生管理系统（2 周）

* 作业布置功能实现（题组生成）
* 学生成绩跟踪、学情统计报表

### 阶段四：英语口语模块 + 可视化分析（2 周）

* ASR 接入 + TTS 反馈系统上线
* 打分算法集成 + 前端得分界面
* 班级报告页面与导出功能
