## 角色职责

### 架构师 (@架构师)
1. 编写实现方案 → 状态设为「已出方案」
2. 指定任务为「待执行」→ 通知程序员
3. 验收已完成任务 → 状态设为「已提交」
4. 协调任务调度和优先级调整

### 程序员 (@程序员)
1. 查看清单中「待执行」的任务
2. 按方案实现功能，撰写开发报告 → 状态改为「已执行」
3. 收到「已审查」后按审查报告修改 → 状态改为「已修改」
4. **禁止执行非待执行的任务**
5. **只有被明确要求时才能执行任务**

### 审查员 (@审查员)
1. 查看清单中「已执行」的任务
2. 审查方案 + 开发报告 + 代码 → 产出审查报告
3. 状态改为「已审查」，添加审查报告文件地址
