# 教师模块改造

## 数据库改造

- 新加 teacher 表，字段有id、账号、密码、姓名、手机号、学科、学校、状态
- ah_student 表 semester 和 subject 字段
- ah_textbook、ah_student、ah_ability、ah_question、ah_question_type 添加 teacher_id 字段
- ah_textbook 添加 units 字段，数据格式为 json，用来保存教材的单元信息，单元信息包括序号、单元名称、单元内容
- 迁移 ah_unit 的数据到 ah_textbook 的 units 字段
- 删除 ah_textbook_version、ah_unit、ah_teacher_book、ah_student_textbook_config 表
 
## 交互改造

### 学生管理

- 老师可以添加学生和认领学生，管理通过审核后学生关联老师
- 删除学生的教材管理
- 学生详情的基本信息加入老师信息模块，展示学生关联的老师，老师信息模块仅管理员可以查看，可以添加关联老师

### 教师管理

- 添加教师的弹窗要对齐数据库字段
- 教师管理列表展示教师基本信息
- 新增教师详情，详情包括基本信息、学生信息、教材信息、能力信息、题目信息
