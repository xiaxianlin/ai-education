# 小学 1–6 年级原子能力清单

> 本文档基于能力建模原则，将能力拆解为 **科目 × 年级 × 可评估的原子能力**，用于出题、诊断、学习路径与 AI 教学决策。

---

## 一、语文（Chinese）

### 一年级
**识字与拼音**
- 能正确拼读声母、韵母和整体认读音节
- 能根据拼音正确书写常用汉字
- 能区分常见形近字

**阅读理解**
- 能理解一句话的基本意思
- 能根据图文内容选择正确答案

**语言表达**
- 能用完整句表达简单意思
- 能按顺序描述简单事件

---

### 二年级
**识字与词语**
- 能理解常见词语的基本含义
- 能在语境中正确选用词语

**句子运用**
- 能判断句子是否通顺
- 能补充句子中的缺失成分

**阅读理解**
- 能找出句子中的关键信息
- 能回答短文中的直接问题

---

### 三年级
**词句理解**
- 能理解词语在具体语境中的含义
- 能进行简单句式转换

**段落理解**
- 能找出段落中心句
- 能判断句子在段落中的作用

**阅读理解**
- 能概括段落大意
- 能根据文本进行简单推断

---

### 四年级
**阅读分析**
- 能区分事实描述与观点表达
- 能理解人物行为原因

**书面表达**
- 能围绕主题写一段条理清楚的文字
- 能使用连接词组织句子

---

### 五年级
**阅读理解**
- 能概括文章主要内容
- 能分析人物形象的基本特点

**写作能力**
- 能围绕中心完成一篇短文
- 能根据提示进行改写或续写

---

### 六年级
**阅读鉴赏**
- 能理解文章写作目的
- 能分析文章结构特点

**综合表达**
- 能清晰表达个人观点并给出理由
- 能对文本内容进行评价或总结

## 四、数据库设计（推荐最终结构）

> 以下数据库结构与本文档中的原子能力一一对应，可直接作为能力系统的核心表设计。

### 4.1 能力域表（ability_domain）

```sql
CREATE TABLE ability_domain (
  id INT AUTO_INCREMENT PRIMARY KEY,
  subject VARCHAR(50) NOT NULL COMMENT '科目',
  code VARCHAR(50) NOT NULL COMMENT '能力域标识',
  name VARCHAR(100) NOT NULL COMMENT '能力域名称',
  description TEXT COMMENT '能力域描述',
  sort_order INT NOT NULL DEFAULT 0,
  is_active TINYINT(1) NOT NULL DEFAULT 1,
  create_time INT NOT NULL,
  update_time INT NOT NULL,
  UNIQUE KEY uk_subject_code (subject, code)
) COMMENT='能力域（一级能力）';
```

---

### 4.2 原子能力表（atomic_ability）

```sql
CREATE TABLE atomic_ability (
  id INT AUTO_INCREMENT PRIMARY KEY,
  subject VARCHAR(50) NOT NULL COMMENT '科目',
  grade INT NOT NULL COMMENT '年级（1-6）',
  domain_code VARCHAR(50) NOT NULL COMMENT '能力域 code',
  code VARCHAR(100) NOT NULL COMMENT '原子能力标识',
  name VARCHAR(200) NOT NULL COMMENT '原子能力名称',
  description TEXT COMMENT '能力描述（可用于提示词）',
  difficulty TINYINT NOT NULL DEFAULT 1 COMMENT '难度 1-5',
  sort_order INT NOT NULL DEFAULT 0,
  is_active TINYINT(1) NOT NULL DEFAULT 1,
  create_time INT NOT NULL,
  update_time INT NOT NULL,
  UNIQUE KEY uk_ability (subject, grade, code),
  KEY ix_subject_grade (subject, grade)
) COMMENT='原子能力（可评估能力）';
```

## 八、学生能力掌握度模型设计

> 本章节定义 **学生 × 原子能力 × 掌握度** 的完整建模方案，用于学情诊断、能力画像与 AI 推荐。

---

### 8.1 核心设计原则

1. **以原子能力为最小评估单元**，不直接评估能力域
2. 掌握度应 **连续可计算**，而非简单对/错
3. 支持：练习、测试、诊断等多来源数据
4. 能随时间滚动更新，反映真实学习状态

---

### 8.2 数据表设计

#### 8.2.1 学生能力掌握表（student_ability_mastery）

```sql
CREATE TABLE student_ability_mastery (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  student_id BIGINT NOT NULL COMMENT '学生 ID',
  atomic_ability_id INT NOT NULL COMMENT '原子能力 ID',
  mastery_score DECIMAL(5,2) NOT NULL COMMENT '掌握度 0–100',
  mastery_level VARCHAR(20) NOT NULL COMMENT '掌握等级',
  correct_count INT NOT NULL DEFAULT 0 COMMENT '正确次数',
  wrong_count INT NOT NULL DEFAULT 0 COMMENT '错误次数',
  last_practice_time INT NOT NULL COMMENT '最近练习时间',
  update_time INT NOT NULL COMMENT '更新时间',
  UNIQUE KEY uk_student_ability (student_id, atomic_ability_id),
  KEY ix_student (student_id),
  KEY ix_ability (atomic_ability_id)
) COMMENT='学生原子能力掌握度';
```

---

### 8.3 掌握度等级划分（推荐）

| mastery_score | mastery_level | 说明 |
|---|---|---|
| 0–39 | unlearned | 未掌握 |
| 40–59 | beginner | 初步掌握 |
| 60–79 | proficient | 基本掌握 |
| 80–100 | mastered | 熟练掌握 |

> `mastery_level` 不作为计算依据，只用于展示与策略判断。

---

### 8.4 掌握度计算模型（工程可用版）

#### 8.4.1 基础计算公式

```text
accuracy = correct_count / (correct_count + wrong_count)
mastery_score = round(accuracy * 100, 2)
```

适用于：
- 初期版本
- 练习量不大

---

#### 8.4.2 平滑修正（推荐）

```text
mastery_score = (correct_count + α) / (correct_count + wrong_count + 2α) * 100
```

- α 推荐取 1–3
- 防止样本过少导致极端值

---

#### 8.4.3 时间衰减（进阶）

```text
decay_factor = e^(-λ * days_since_last_practice)
final_score = mastery_score * decay_factor
```

- λ 控制遗忘速度（如 0.02）
- 用于长期未练习能力的降权

---

### 8.5 掌握度更新策略（事件驱动）

每次学生完成一道题：

1. 题目 → atomic_ability_id
2. 更新 correct_count / wrong_count
3. 重新计算 mastery_score
4. 更新 mastery_level
5. 刷新 last_practice_time

---

### 8.6 AI 教学与推荐规则示例

#### 8.6.1 补弱推荐

```text
选择 mastery_score < 60 的能力
按（年级优先 → 分数升序）排序
```

#### 8.6.2 提升训练

```text
选择 mastery_score ∈ [60,80)
进行强化练习
```

#### 8.6.3 跳过策略

```text
mastery_score ≥ 80
降低该能力出题频率
```

---

### 8.7 与前置能力的联动（可扩展）

若引入 `ability_prerequisite` 表：

```text
若 前置能力 mastery_score < 60
则 后置能力 不进入推荐池
```

## 九、总结

- 原子能力是评估与教学的最小单元
- 掌握度模型决定了 AI 系统“是否聪明”
- 本模型可逐步从简单准确率演进到时间感知模型
