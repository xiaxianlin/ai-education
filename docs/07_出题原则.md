| 科目 | 题型                                     | 举例                     |
| ---- | ---------------------------------------- | ------------------------ |
| 数学 | 单选、填空、解答、判断题、步骤题、图形题 | 解方程、几何证明、应用题 |
| 英语 | 选择、完型、阅读理解、写作、语法填空     | 找主旨、改错、作文续写   |

| 层级 | 类型                   | 举例               |
| ---- | ---------------------- | ------------------ |
| 记忆 | 基础知识点背诵         | 定义、单词释义     |
| 理解 | 用自己的话解释         | 概念对比           |
| 应用 | 公式运用、语法句型造句 | 数学运算、英文写作 |
| 分析 | 找出关系               | 找错误、找因果     |
| 评价 | 判断对错、比较         | 多种方法优劣分析   |
| 创造 | 自己命题、综合题       | 应用题编写         |

高质量题目应具备：
目标明确：针对具体知识点/技能点

难度合理：符合认知发展水平（可引入 IRT 难度模型）

干扰项合理（选择题）：迷惑项必须“像真但错”

情境真实：特别是应用题，应贴近学生生活

题干简洁清晰：不引发歧义
