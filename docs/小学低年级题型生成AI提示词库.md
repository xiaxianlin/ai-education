
## 概述说明

本提示词库专为K12在线练习APP设计，针对小学低年级（1-3年级）语文、数学、英语三个学科，提供系统化的题型生成AI提示词。提示词库覆盖三种核心应用场景：日常训练、单元测试、综合评估，帮助AI精准生成符合教学目标和学生认知特点的练习题目。

## 提示词设计原则

### 场景差异化设计

**日常训练场景**

- **目标定位**：单一知识点强化，快速掌握

- **核心特征**：即时反馈、游戏化设计、碎片化学习

- **题量设置**：3-5题为一组，支持多次练习

- **难度策略**：聚焦单一难度层次，确保成功体验

- **反馈机制**：每题即时反馈，错题提供详细解析

**单元测试场景**

- **目标定位**：单元知识点全面检测

- **核心特征**：知识点覆盖完整、难度梯度合理

- **题量设置**：10-15题，完整测试单元

- **难度策略**：易中难比例6:3:1，符合学生能力分布

- **时间限制**：设置合理时长，培养答题节奏

**综合评估场景**

- **目标定位**：跨单元知识整合与能力考查

- **核心特征**：知识综合运用、能力分层评估

- **题量设置**：15-20题，全面评估学习成果

- **难度策略**：按识记、理解、应用三层次分布（5:8:7）

- **综合性**：涉及多单元内容，注重知识迁移

### 低年级适配原则

1. **认知发展匹配**：符合具体形象思维特点，图文比例高

2. **注意力管理**：单次练习时长控制在8-15分钟

3. **趣味性保障**：融入游戏化元素，保持学习动力

4. **即时鼓励**：正向反馈为主，建立学习自信

## 语文学科提示词

### 一年级语文

#### 日常训练 - 拼音专项

**场景说明**：单一拼音知识点强化训练

**适用年级**：一年级上学期

**知识点范围**：单个声母/韵母/整体认读音节

**题型组合**：

- 看图选拼音（3题）

- 拼音拼读（2题，语音评测）

**难度设置**：基础层次，正确率目标80%以上

**数量建议**：5题/组，支持连续3组练习

**AI生成指令**：

```plaintext
生成一组一年级拼音专项日常训练题目，要求：

1. 知识点：仅聚焦【单韵母a/o/e】或【声母b/p/m/f】（二选一）
2. 题型配置：
   - 看图选拼音3题：每题展示清晰的物品图片，提供4个拼音选项（1对3错）
   - 拼音拼读2题：显示拼音，学生跟读，系统评测发音
3. 图片要求：
   - 使用彩色卡通风格
   - 物品为一年级学生熟悉的日常事物
   - 图片主体清晰，背景简洁
4. 难度控制：
   - 干扰项选择形近或音近的拼音
   - 避免超出当前知识点范围
5. 游戏化设计：
   - 每题设置答题倒计时动画（非强制）
   - 正确后显示"太棒了！"等鼓励语
   - 全对后解锁小星星奖励
6. 即时反馈：
   - 答对：显示绿色对勾+鼓励语+自动进入下题
   - 答错：显示正确答案+语音播放正确读音+"再试一次"按钮
```

**难度设置**：基础层次，单字识别

#### 单元测试 - 拼音单元

**场景说明**：拼音学习阶段性检测

**适用年级**：一年级上学期

**知识点范围**：声母、韵母、音节拼读、声调

**题型组合**：

- 看图选拼音（4题）

- 声母韵母识别（3题）

- 拼音拼读（3题）

- 拼写音节（2题）

**难度设置**：易6题、中4题、难2题

**数量建议**：12题，建议15分钟完成

**AI生成指令**：

```plaintext
生成一份一年级拼音单元测试卷，要求：

1. 测试范围：覆盖已学完的声母、韵母、整体认读音节、四声调号
2. 题型与数量：
   - 看图选拼音（4题）：2题易，2题中
   - 声母韵母识别（3题）：判断声母或韵母，2题易，1题中
   - 拼音拼读（3题）：语音评测，1题易，1题中，1题难

   - 易（6题）：单韵母、简单声母、常见音节

4. 知识点分布：
   - 声母考查：3题
   - 韵母考查：3题
   - 音节拼读：4题
   - 声调辨识：2题
5. 测试体验：
   - 题目按难度从易到难排列
   - 每5题设置一个休息提示点
   - 完成后显示知识点掌握雷达图
   - 提供错题本功能，可重点练习
6. 评分标准：
   - 90分以上：优秀，显示"拼音小达人"
   - 80-89分：良好，显示"继续加油"
   - 80分以下：需加强，推送针对性训练
```

- 笔画笔顺（2题）

- 组词填空（3题）

- 看图写字（2题）

**难度设置**：易7题、中5题、难2题

**数量建议**：14题，建议18分钟完成

**AI生成指令**：

```plaintext
生成一份一年级识字与写字单元测试卷，要求：

1. 生字范围：第X单元15-20个生字（需指定单元）
2. 题型配置：
   - 看图识字（4题）：每题4个选项，2易2中
   - 字形辨析（3题）：区分形近字，2易1中
   - 笔画笔顺（2题）：判断笔画数或笔顺，1中1难
   - 组词填空（3题）：选词填空，1易1中1难
   - 看图写字（2题）：手写输入或选字，1中1难
3. 难度分层：
   - 易（7题）：高频字、象形字、简单结构
   - 中（5题）：合体字、同音字辨析、常用词语
   - 难（2题）：笔画多的字、易错字、灵活运用
4. 知识点覆盖：
   - 字音识别：4题
   - 字形辨认：4题
   - 字义理解：3题
   - 笔画笔顺：2题
   - 综合运用：1题
5. 技术实现：
   - 看图识字题配清晰彩图
   - 笔顺题提供动画演示（答题后）
   - 写字题支持手写识别（准确率要求80%）
   - 实时显示答题进度
6. 测评反馈：
   - 生成生字掌握情况分析
   - 标注未掌握生字，推送专项练习
   - 笔画笔顺错误给予详细纠正
   - 提供单元生字复习建议
```

#### 综合评估 - 期中/期末测试

**场景说明**：跨单元综合能力考查

**适用年级**：一年级期中/期末

**知识点范围**：拼音、识字、词语、句子、阅读

**题型组合**：

- 拼音部分（4题）：选拼音、拼读

- 识字部分（5题）：识字、组词、字形

- 词句部分（4题）：词语搭配、补充句子

- 阅读部分（3题）：短文阅读理解

**难度设置**：识记8题、理解5题、应用3题

**数量建议**：16题，建议25分钟完成

**AI生成指令**：

```plaintext
生成一份一年级语文综合评估测试卷（期中/期末），要求：

1. 测试范围：第1-X单元所有内容（需指定具体单元范围）
2. 模块设置：
   【拼音部分】（4题，占25%）
   - 看图选拼音2题（跨单元生字）
   - 拼音拼读2题（含二三声、整体认读）
   
   【识字部分】（5题，占31%）
   - 看图识字2题（不同单元生字）
   - 字形辨析2题（形近字对比）
   - 笔画笔顺1题（难点字）
   
   【词句部分】（4题，占25%）
   - 词语搭配1题（量词或形容词）
   - 反义词/近义词1题
   - 补充句子2题（"谁在做什么"句式）
   
   【阅读部分】（3题，占19%）
   - 提供一篇80-120字的短文（配3-4幅图）
   - 问题1：人物/地点识别（识记）
   - 问题2：事件理解（理解）
   - 问题3：简单推断或感受（应用）

3. 能力层次分布：
   - 识记（8题）：拼音识别、生字认读、词语再认
   - 理解（5题）：字义理解、句意把握、段意概括
   - 应用（3题）：词语运用、句子仿写、情感体会

4. 难度梯度：
   - 各模块内由易到难排列
   - 拼音、识字模块相对简单，确保基础分
   - 阅读模块有挑战性，拉开分数差距

5. 综合性体现：
   - 生字覆盖所有单元，不重复出现
   - 短文主题贴近学生生活（校园、家庭、自然）
   - 问题设计体现知识迁移能力

6. 评测与反馈：
   - 生成详细的能力雷达图（拼音、识字、词句、阅读）
   - 标注薄弱知识点，给出复习建议
   - 提供错题解析和同类题推荐
   - 85分以上评为优秀，60-84分良好，60分以下需重点辅导
```

## 使用说明

### 如何使用本提示词库

1. **选择适用场景**：根据教学需求，选择日常训练、单元测试或综合评估场景。

2. **确定学科年级**：定位到具体的学科（语文/数学/英语）和年级（一年级/二年级/三年级）。

3. **选择题型类型**：在对应场景下，选择具体的题型专项（如拼音专项、计算专项、词汇专项）。

4. **复制提示词**：将对应的AI生成指令复制到题目生成系统中。

5. **自定义参数**：根据实际需求，修改提示词中的参数（如单元范围、知识点、难度等）。

6. **生成题目**：系统根据提示词自动生成符合要求的题目。

7. **质量检查**：检查生成题目的准确性、适切性和趣味性，必要时微调。

### 提示词优化建议

- **精准指定范围**：明确单元、知识点、词汇主题等具体范围，确保生成内容精准。

- **平衡难度分布**：根据学生实际水平，调整易中难题目比例。

- **强化反馈机制**：确保题目配有即时反馈和详细解析，支持学生自主学习。

- **融入趣味元素**：低年级学生注意力有限，游戏化和趣味性设计至关重要。

- **定期迭代更新**：根据学生练习数据和反馈，持续优化提示词库。

### 注意事项

- 本提示词库基于小学低年级学生的认知特点设计，使用时需考虑学生的实际水平。

- AI生成的题目需要经过人工审核，确保内容准确、无歧义、符合教学目标。

- 不同场景的提示词侧重点不同，不可混用，以免影响题目质量。

- 定期收集学生练习数据，分析薄弱环节，针对性地使用相应提示词生成强化训练题目。
