**技术方案：基于教材自动生成题库系统（数学与英语）**

---

## 一、项目目标

基于中国 K12 教材（数学和英语），利用大语言模型（LLM）自动生成高质量、结构化的题库内容，减少人工出题工作量，支持个性化学习与动态练习。

---

## 二、整体架构

```text
[教材上传] → [OCR 模块] → [结构化提取模块] → [知识点抽取] → [LLM 题目生成] → [题目审核/编辑] → [结构化题库] → [学生练习系统]
```

---

## 三、模块详解

### 1. 教材上传模块

* 支持格式：PDF、图像（JPG/PNG）、Word
* 自动保存上传记录与版本控制

### 2. OCR 模块（可选）

* 工具：PaddleOCR / Tesseract / 腾讯文智
* 目标：提取章节、段落、例题、重点句
* 结构化输出：章节层级、文本内容、图片标注（公式、图形等）

### 3. 教材结构化提取

* 基于正则 + 文本分析，识别标题（第几章、第几节）、知识点说明、例题
* 工具建议：spaCy / HanLP + 自定义规则
* 输出样例：

```json
{
  "年级": "三年级",
  "章节": "分数加减法",
  "知识点": ["同分母加法", "异分母通分"],
  "例题": ["3/5 + 1/5 = ?"]
}
```

### 4. 知识点抽取

* 依据关键词/语言模式识别知识点表述
* 可建立一个本地“知识点词库”辅助判断（如教材大纲）

### 5. LLM 题目生成模块

* 模型：GPT-4 / Claude / 通义千问
* Prompt 模板：按知识点生成不同题型

#### 数学 Prompt 示例：

```
请根据以下知识点，为小学三年级学生生成5道数学题：
知识点：同分母分数加法
要求：题型包含填空、选择、应用题；每题需给出答案与解析。
```

#### 英语 Prompt 示例：

```
教材句子：This is my pencil. That is your ruler.
请生成4道英语练习题，题型包括：单词拼写、语法选择、图片选词、对话排序。
附答案。
```

### 6. 题目自动审核 + 人工校对工作流设计

#### 自动审核模块：

* 校验逻辑一致性（如答案是否符合解析）
* 检查语法错误、题型格式错误
* 过滤敏感词、重复题、低质量提示（基于规则 + LLM 自检）
* 工具：Pydantic 规则校验 + Prompt-Based 验证 LLM 输出质量

#### 审核流程建议：

```text
[AI生成题目] → [系统初审（规则 + AI判定）] → [标记问题题目] → [编辑后台列表] → [人工快速校对] → [确认发布]
```

* 提供“高亮可疑区域”、“一键建议修改”功能
* 设置“审核通过率”阈值，超限即需人工确认

### 7. 结构化题库存储

* 数据库设计：题干、答案、解析、题型、知识点、章节、年级、标签等
* 推荐使用 PostgreSQL / MongoDB
* 支持版本历史与题目变式管理

### 8. 英语口语评测模块设计（ASR + TTS + 打分）

#### 模块组成：

1. **TTS 模块**（Text-to-Speech）

   * 用于播放标准音频（朗读例句）
   * 工具：Aliyun TTS、Edge TTS、百度合成

2. **录音上传与识别（ASR）**

   * 工具：Aliyun ASR、Whisper、讯飞语音识别
   * 输出格式：用户音频 → 文字转写 + 音素级评分

3. **口语评分系统**（Pronunciation Evaluation）

   * 维度：准确度（Accuracy）、流利度（Fluency）、完整度（Integrity）
   * 工具建议：讯飞开放平台、科大讯飞 ISE API
   * 输出示例：

```json
{
  "句子": "This is my book.",
  "识别": "Dis is my book.",
  "打分": {
    "准确度": 78,
    "流利度": 90,
    "完整度": 95
  },
  "建议": "注意 th 发音，尾音清晰"
}
```

4. **练习内容生成**

   * 根据课本内容 + 场景，自动生成口语练习素材
   * 题型示例：跟读、复述、角色对话、句子纠错

### 9. 练习系统（MVP）

* 前端：React / Vue / 微信小程序
* 功能：

  * 学生按章节练习
  * 随机题组生成
  * 练习记录与错题本
  * 答题结果分析

## 四、开发建议

### 技术栈

| 层级     | 推荐技术                            |
| ------ | ------------------------------- |
| 前端     | React + Vite / 微信小程序            |
| 后端     | FastAPI + PostgreSQL / MongoDB  |
| OCR    | PaddleOCR / 腾讯云 OCR             |
| LLM 接入 | OpenAI GPT-4 / 阿里通义 / 文心一言 API  |
| 语音相关   | Aliyun ASR/TTS / Whisper / 讯飞评测 |

### 服务模式

* 将题目生成部分拆成独立服务（支持异步请求）
* 添加缓存与“生成记录”，避免重复生成

## 五、DEMO 示例

以下为数学题目生成 Python 脚本原型：

```python
import openai

openai.api_key = "your-api-key"

prompt = """
请根据以下知识点，为小学三年级学生生成5道数学题：
知识点：同分母分数加法
要求：题型包含填空题、选择题、应用题；每题需给出答案与解析。
输出格式：JSON 数组
"""

response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": prompt}
    ],
    temperature=0.7
)

print(response.choices[0].message["content"])
```
